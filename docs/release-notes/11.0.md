## Fixed

- **Pop-ups no longer vanish when you rotate the screen.** Opening the Backup or Restore preview and turning the phone used to close it with no warning. The pop-up now stays open and changes shape with the orientation — a centred card in portrait, a slide-up panel in landscape — and back again when you rotate back. The same fix applies to the profile picture, username and link pop-ups, the Send feedback chooser, and the app icon, background effects, celebrations and sparkles panels.
- **The "Change profile picture" pop-up now fits in landscape.** Turned sideways there was not enough height for the avatar grid, so it was squashed down to a sliver and the controls bunched up against the buttons. The pop-up now scrolls as a whole in landscape, so every avatar and button keeps its proper size. Portrait is unchanged.
