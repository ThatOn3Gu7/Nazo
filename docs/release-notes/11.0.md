## New

- **Press and hold your profile picture to see it full size.** A quick tap still opens the "Change profile picture" pop-up exactly as before.
- **Choose how the sound effects sound.** Settings → Feedback → Sound style offers Chime, Arcade, Marimba and Bell. Tap one to hear it; the choice applies to every sound in the app. Chime is the original sound and stays the default.

## Improved

- **Quiz questions show which anime they are about.** Each question now carries its series name (for example, "Attack on Titan" on a "What is the name of the first arc?" question), so generic wording can no longer be mistaken for another anime's question.
- **The guessing game downloads each mystery image only once.** The picture used to be fetched twice per round (once to prepare it and once to display it); it now arrives over the network a single time, and unreasonably large images are refused instead of being buffered — less mobile data per round, and a broken or hostile image host can no longer stall the game.
- **Clearer text and buttons in every colour theme.** All 15 accent colours, in both light and dark mode, now meet accessibility contrast standards. Placeholder text, success/error notices and button labels are easier to read, disabled buttons stay legible instead of fading out, buttons are easier to tap, and every button now uses the app's own font.
- **A tidier home screen.** The page now reads top-to-bottom in one clear order — brand, status, Daily Challenge, game mode, topic, difficulty, count, start — with less empty space and less card clutter. The start button sits far closer to the fold, and every option and saved selection works exactly as before.
- **Play screens now lead with the question.** The header shows which question or round you're on in bold, with the anime and arc underneath instead of competing with it, and the question card no longer repeats the franchise above the question. Correct, wrong and timed-out answers are named out loud in the explanation panel ("Time's up!" used to be hinted only by the timer's colour). The timer disc turns red as a whole in its final seconds in both games, Blitz shows the remaining time as a draining bar, the Daily Challenge run wears a DAILY badge, and the drifting background lanterns dim behind gameplay so nothing floats under the text.
- **Results screens celebrate without hiding the result.** Confetti now plays behind the score, stats and buttons instead of drifting across them, so nothing on a result screen is ever obscured. Each result leads with the number that matters for its mode — the correct count for Survival and Blitz, accuracy for a quiz — with the other kept right beside it, the replay action is clearly the strongest button everywhere, and the answer review names your answer and the correct answer in words (and says when a question went unanswered), with each explanation in its own panel.

## Fixed

- **Pop-ups no longer vanish when you rotate the screen.** Opening the Backup or Restore preview and turning the phone used to close it with no warning. The pop-up now stays open and changes shape with the orientation — a centred card in portrait, a slide-up panel in landscape — and back again when you rotate back. The same fix applies to the profile picture, username and link pop-ups, the Send feedback chooser, and the app icon, background effects, celebrations and sparkles panels.
- **The "Change profile picture" pop-up now fits in landscape.** Turned sideways there was not enough height for the avatar grid, so it was squashed down to a sliver and the controls bunched up against the buttons. The pop-up now scrolls as a whole in landscape, so every avatar and button keeps its proper size. Portrait is unchanged.
- **The daily streak now resets when you miss a day.** Skipping a day left the old streak number on screen until you next finished a quiz. An inactive day is now recognised as soon as anything looks at your stats, so Home, Profile, Statistics and the widget all agree. Your best streak is never affected.
- **The update panel and the profile picture preview also survive rotation now.** Turning the phone while checking for an update, reading release notes, or previewing and cropping a new profile picture no longer throws the panel away.
- **Wrong answers in the question bank were put right.** One question credited Frieren with Trigun's priest and several "which arc comes next" questions had the wrong arc; the practice deck also mixed up similar questions from different series.
- **AI-generated quizzes can no longer be scored on a wrong answer.** If the AI's reply is broken (an answer that does not match its options, fewer than four choices, repeated choices, or not enough valid questions), the app now rejects it, quietly retries once with your alternate model, and otherwise offers the local quiz — instead of silently marking the first choice as "correct".
- **The Daily Challenge is now the same five questions all day, every time.** Leaving mid-run and starting again — even after force-closing the app — shows the identical questions with the identical answer order. (Previously the answer order could reshuffle between starts.)
- **Restoring a backup now updates the whole app immediately.** After a restore, the theme, accent, profile, sounds, statistics, question history and practice deck all refresh right away — previously you had to restart the app before the restored data showed everywhere. Restoring also verifies the backup file first and only reports success once everything has actually been written.
- **Backups now include your custom profile picture.** The picture file itself travels inside the backup, so restoring — on this phone or a new one — brings back the exact picture instead of a blank avatar. Older backups made before this change still restore normally.
- **Backup and restore no longer slow the screen down.** Previews, exports and restores of large backups could briefly freeze the interface while files were read and written; that work now happens in the background. Automatic backups are also written safely: if a write is interrupted, the previous backup stays intact.
